# Aplicatie bancara #

- Interogari posibile in sistem:
  1. Adauga un client nou (normal sau premium)
  2. Creeaza un cont bancar pentru un client
  3. Emite un card bancar asociat unui cont
  4. Efectueaza o tranzactie (depunere/retragere/transfer)
  5. Genereaza extras de cont pentru o perioada
  6. Afiseaza istoricul tranzactiilor unui cont
  7. Cauta un client dupa CNP sau nume
  8. Cauta un cont dupa IBAN
  9. Listeaza toti clientii ai bancii
  10. Listeaza toti clientii premium ai bancii
  11. Calculeaza soldul total al unui client (toate conturile)
  12. Sterge un cont bancar (cu validari)
  13. Elimina un client din sistem
  14. Listeaza toate cardurile dintr-o banca
  15. Blocheaza un card bancar
  
- Lista obiecte
    1. Persoana
    2. Client
    3. ClientPremium
    4. ContBancar
    5. CardBancar
    6. Tranzactie
    7. ExtrasDeCont
    8. Banca
    9. IstoricTranzactii
